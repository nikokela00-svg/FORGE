# docs

Product and architecture documentation. The law of the codebase.

- `PRD.md` — product requirements, pillars, non-goals, success metrics.
- `ARCHITECTURE.md` — system diagram, layer responsibilities, persistence.
- `adr/` — Architecture Decision Records (context → decision → consequences
  → alternatives). Append, never rewrite history.

Keep documentation in sync with the code (Definition of Done item 7).
